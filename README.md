# DailyPhrases – Täglicher Deutsch-Vokabeltrainer

Eine Progressive Web App (PWA) zum Lernen von Deutsch mit intelligentem
Spaced Repetition und automatischer Level-Anpassung.

## Funktionen

- Tägliche Vokabelübungen mit Spaced Repetition
- Automatische Schwierigkeitsanpassung anhand deiner Resultate
- Fortschritts-Dashboard
- Alltags- und arbeitsbezogener Wortschatz (Schweiz, Deutschland, Österreich)

## Technologie

- React + Vite + TypeScript + Tailwind CSS
- Supabase (Authentifizierung + Datenbank)
- Stripe (Zahlungen)
- Netlify (Hosting)
